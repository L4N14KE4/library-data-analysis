# 도서관 장서 데이터 분석 — Claude Code 멀티 에이전트 작업환경

가상의 구립도서관 장서 목록(28,000권, 2023~2025년 3년 대출 집계)으로 자료구입 예산 배분과 장서 정리 방향의 근거를 찾은 팀 프로젝트 기록이다.
분석은 Claude Code의 메인 세션과 서브에이전트 네 개가 나눠 맡았고, 질문 확정·품질 처리·계산 방법·최종 요약은 모두 사람이 승인했다.

## 작업 방식

분석 하나는 9단계를 거치고, 그중 4곳(질문 확정, 품질 처리, 계산명세, 최종 요약)에서 사용자 승인을 받아야 다음으로 넘어간다.
분석 담당과 검증 담당은 서로의 결과를 보지 않고 원자료에서 따로 계산한 뒤 수치를 대조한다.

| 담당 | 에이전트 | 하는 일 | 일부러 막은 것 |
|---|---|---|---|
| 진행 | 메인 세션 | 묻기, 승인받기, 기록, 일 나누기 | 직접 계산하지 않는다 |
| 계획 | `analysis-planner` | 확정된 질문을 계산명세로 옮긴다 | 실행 도구 없음 |
| 분석 | `data-analyst` | 점검, 품질 문제 정리, 분석 | 검증/ 폴더를 열지 않는다 |
| 검증 | `independent-verifier` | 계산명세 검토, 독립 재계산, 대조, 해석 검토 | 자기 값을 저장하기 전에는 분석/ 폴더를 열지 않는다 |
| 요약 | `report-summarizer` | 해석, 최종 요약 | 실행 도구 없음 — 새 수치를 만들 수 없다 |

자세한 흐름·규칙·권한은 [작업환경_안내.md](작업환경_안내.md)에 있다.

## 다시 돌려 보기

1. [uv](https://docs.astral.sh/uv/getting-started/installation/)를 설치하고 레포 루트에서 환경을 만든다.

    ```bash
    uv venv
    uv pip install -r requirements.txt
    ```

2. 차트를 다시 그리려면 [나눔고딕](https://hangeul.naver.com/font) `NanumGothic.ttf`를 레포 루트에 둔다.
3. 각 작업 폴더의 스크립트는 레포 루트를 기준으로 원자료를 읽는다.

    ```bash
    .venv/bin/python 작업/20261117_무대출_주제분포/분석/분석.py
    ```

4. 새 질문을 분석하려면 Claude Code에서 이 폴더를 열고 대화창에 질문을 적는다.

## 데이터 안내

원자료는 수업 사례집에서 받은 가상 데이터다. 도서관·서명·저자·출판사는 실제와 관계없다.
팀 데이터 코드북(`데이터코드북.docx`)은 작성자 정보가 들어 있어 레포에 넣지 않았다. 지침과 작업 기록에 나오는 코드북 절 번호는 이 파일을 가리킨다.

## 6. 진행 담당에게 — 사용자에게 물을 것

1. P1 최근대출일 빈칸 14,036행을 어떻게 처리할지 (유지 / 제외 / 대체). 빈칸 행은 대출횟수 0인 행과 정확히 같다. 제외하면 0회 책이 모두 빠진다 (평균 2.5125 → 5.0380, 0 비율 50.13% → 0%, 제거 50.13%).
2. 코드북 5절 '처리: N/A'의 뜻 (M5): (가) 처리하지 않음(해당 없음)인지, (나) 빈칸을 'N/A' 표기로 바꾸라는 뜻인지.
3. P7 통계적 이상치 기준 (코드북에 없음): IQR 1.5배 / IQR 3배 / 평균±3표준편차 / 통계적 이상치는 보지 않음. 기준을 고르면 처리(유지 / 제외 / 대체)도 정해야 한다. 대출횟수 해당 행: 2,811 / 1,628 / 210, 구입가격: 149 / 0 / 48.
4. P6 자료ID만 다른 16쌍(32행, 모두 대출 0회)을 같은 책의 중복으로 볼지. 확인하려면 코드북 1-1절 '삭제' 열(서명·저자 등)을 이 확인에만 볼 수 있게 허용할지도 정해야 한다.
5. P5 최근대출일 = 구입일인 712행(하루 뒤인 행은 185행)이 정상인지.
6. P2·P3 코드북 표기 (M1~M4): KDC '0 ~ 900' → 실제 '000 ~ 900' 3자리 표기, 발행년 타입 '날짜' → 실제 연도 정수, 최근대출일 하한 빈칸 → 실제 2023-01-01, 인코딩 'UTF-8 / CP949' → 실제 BOM 붙은 UTF-8. 코드북을 실제에 맞춰 고칠지, 데이터를 코드북 표기에 맞출지 (코드북은 사용자 파일이라 분석 담당은 고치지 않는다).

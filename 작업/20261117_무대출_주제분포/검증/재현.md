## 1. 실행한 명령 (프로젝트 폴더 `/Users/laniakea/dev/data-litaracy/`에서)

```

```

- 실행 명령은 진행 담당이 알려 준 명령, 분석.py 2줄 주석, 최종요약.md 8항과 같다.
- 분석 코드는 분석.py 하나라서 실행 순서 문제는 없다.
- 처음 실행할 때 내 셸 명령 안의 구분 문자열(`====`)을 zsh가 명령으로 읽어 그 자리에서 실행이 멈췄다. 이때 분석.py는 실행되지 않았다(파일 수정 시각이 그대로였다). 같은 명령을 구분 문자열 없이 다시 실행했다. 분석 코드 문제가 아니다.
- 표준 출력: `N1=28000 N2=22699 N3=11363 N4=40.58 N5=0 N56=50.06`. 코드 안의 멈춤 점검(N5≠0, 주제 값 10개, 합계, 동률)에는 하나도 걸리지 않았다.

## 5. 라이브러리 버전

`.venv/bin/python -m pip freeze`는 **실패**했다: `No module named pip`. 이 가상환경에는 pip가 설치돼 있지 않다.
pip를 설치하지 않았다(공통규칙: 설치하지 말고 알린다). 대신 `importlib.metadata.version()`으로 실제 설치 버전을 읽었다.

| 라이브러리 | 설치 버전 (importlib.metadata) | requirements.txt | 분석.py에서 import |
|---|---|---|---|
| Python | 3.11.13 | — | — |
| pandas | 3.1.1 | 3.1.1 | 예 |
| numpy | 2.4.6 | 2.4.6 | 아니오 (pandas가 씀) |
| matplotlib | 3.11.2 | 3.11.2 | 아니오 |
| scipy | 1.17.1 | 1.17.1 | 아니오 |
| python-dateutil | 4.0.0 | — | 아니오 (pandas가 씀) |
| tzdata | 2026.6 | — | 아니오 (pandas가 씀) |

분석.py가 직접 import하는 것은 표준 라이브러리 csv, sys, decimal과 pandas다. 설치 버전과 requirements.txt 버전이 같다.

## 7. 제안 (수행하지 않음)

- 최종요약 8항에 Python 3.11.13을 적고, "이 가상환경에는 pip가 없다. 버전은 importlib.metadata로 확인했다"를 덧붙이면 팀원이 재현할 때 덜 헤맨다.

# 규칙 점검표 — 3년 무대출 장서의 주제별 분포 (분석/ 산출물)

점검 대상: `분석/분석.py`, `분석/결과.md`, `분석/핵심수치.csv`, `분석/주제별_무대출표.csv`
기준: `시스템프롬프트_공통규칙.md` 규칙 1~10, `계산명세.md`, `승인기록.md` 1~10번

| 규칙 번호 | 지켰는가 (예 / 아니오 / 해당 없음) | 근거 (파일·줄) |
|---|---|---|
| 1. 코드북에 없는 값의 의미를 지어내지 않는다 | 예 | 분석.py 12행: 주제 10개를 코드북 2절 값 그대로 썼다. 49~50행: 다른 값이 있으면 멈춘다. 결과.md 11행: '무대출'의 정의를 계산명세 2절 용어 그대로 적었다. 코드북에 없는 값 해석은 없다. |
| 2. 모든 수치에 산출 코드를 함께 낸다 | 예 (작은 지적 2건) | 결과.md 6행에 코드 경로와 실행법이 있다. 19~24행, 31행, 58~62행에서 모든 수치에 분석.py 줄을 붙였고, 확인해 보니 실제 줄과 맞다. 지적 ① 결과.md 7행 '분석.py 12'는 11행(`COLS`)이 맞고, 8행 '16~19'는 15~18행(`pct`)이 맞다. 지적 ② 분석.py 90행의 합계 비중 "100.00"은 계산이 아니라 문자열로 써 넣었다. 값은 N3÷N3×100과 같다. 셋 다 수치에는 영향이 없다. |
| 3. 사실과 추정을 갈라 쓴다 | 예 | 결과.md 13행 '데이터에서 확인된 사실' 아래에는 센 값과 분모 설명만 있다(26~27행, 48~52행). 해석이나 추정 문장이 없다. |
| 4. 결측·이상치·중복을 임의로 처리하지 않는다 | 예 | 분석.py 29~32행: 행을 지우지 않았다. 30행의 최근대출일 NaN→빈 문자열·strip은 계산명세 2절 '빈칸' 정의 그대로다. 결과.md 7행: 자료ID만 다른 24행은 승인 8번대로 유지했다. |
| 5. 검정 방법을 하나의 기준으로 고르지 않는다 | 해당 없음 | 계산명세 5절: 기술분석이라 검정 0회다. 결과.md 9행 '검정 0회'. 분석.py에 검정 코드가 없다. |
| 6. 요청하지 않은 분석을 하지 않는다 | 예 | 분석.py 62~90행은 계산명세 6절 N1~N56과 7절 표 1(승인 9번의 대상 권수 열 + 합계 행)만 만든다. 92~96행 출력은 계산명세 6절 '합 확인'에 해당한다. 차트가 없다(승인 6번). |
| 7. 통계 용어에 한 줄 설명을 붙인다 | 해당 없음 | 검정·p값·신뢰구간을 쓰지 않았다(계산명세 5절). 결과.md 8행 '사사오입'은 반올림 방식 설명이다. 결과.md 49~51행에서 비율 두 가지의 분모를 풀어 적었다. |
| 8. 변수가 측정한 범위를 넘는 표현을 쓰지 않는다 | 예 | 결과.md 11행: '무대출'을 구입일·기간·대출횟수 0으로 한정했다. '가치 없음'·'제적 대상'·'이용자 관심' 같은 확장 표현이 없다(1~64행 전체 확인). 26행에서 40.58%의 분모에 대상 밖 책이 들어 있음을 밝혔다. |
| 9. 관찰 데이터를 인과로 서술하지 않는다 | 예 | 결과.md 1~64행에 원인·영향을 말하는 문장이 없다. |
| 10. 차트 한글 깨짐 방지 | 해당 없음 | 승인 6번 '빼고 표만'에 따라 차트를 만들지 않았다. 분석.py에 matplotlib 사용이 없다(1~96행). |

요약: 아니오 0건, 예 7건(규칙 2에 작은 지적 2건), 해당 없음 3건(5, 7, 10).

참고 (규칙 밖, 공통 원칙)

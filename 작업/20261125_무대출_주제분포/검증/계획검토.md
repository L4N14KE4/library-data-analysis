## 2. 핵심 수치가 두 가지로 계산될 수 있는지

N1~N56 각각을 한 가지로만 계산할 수 있는지 아래 점을 보았다. 모두 한 가지로 정해져 있다.

| 본 점 | 계산명세의 정의 | 판정 |
|---|---|---|
| 전체 비율 분모 (N4) | N1 = 28,000 (대상 아님). 표 위 문장에 분모를 밝힘 | 한 가지 |
| 주제 안 비율 분모 (N8 등) vs 합계 행 (N56) | 주제 대상 권수 / 대상 전체 N2. 평균 아님을 각주로 | 한 가지 |
| 대상 경계 | 구입일 ≤ 2022-12-31, 날짜 변환 후 비교 (당일 구입 0권이라 < / ≤ 차이도 없음) | 한 가지 |
| 무대출 | 대출횟수(정수) == 0, 최근대출일은 확인(N5)에만 | 한 가지 |
| 빈칸 | 공백 제거 후 빈 문자열, NaN 포함 | 한 가지 |
| 반올림 | 정확한 분수 → ROUND_HALF_UP 소수 둘째 자리, csv에 반올림 값 | 한 가지 |
| 순위 (마) | 무대출 권수 오름차순 1~10, 동률이면 멈춤 | 한 가지 |
| 주제 번호 | 코드북 2절 순서 고정 | 한 가지 |
| 중복 24행 | 유지 (승인 8번) | 한 가지 |

## 1. 확정된 질문 (질문.md, 승인 3번(원래 3번))

> `P02_장서목록_대출횟수` 28,000권 가운데 구입일이 2022-12-31 이하이면서 2023-01-01~2025-12-30 3년간 대출횟수가 0인 책(무대출, 질문 1과 같은 정의)의 구입가격 합계를 구하고, 이것이 전체 28,000권 구입가격 합계(총 장서구입비)에서 차지하는 비중(%)을 구한다. '무대출 / 나머지' 두 조각 원그래프에 비중과 금액을 표시하고, 핵심 문장으로 요약한다.

분석 유형: 기술분석 (맥락 파일 메모 5). 검정 없음.
위 인용 안의 '총 장서구입비'는 질문 원문이라 그대로 둔다. 이 문서의 다른 곳과 산출물에서는 '구입가격 합계(현재 목록 28,000권)'로 부른다 (승인 7번(원래 7번), 2절).

- IQR(사분위범위): 값을 크기순으로 놓았을 때 가운데 50%가 퍼진 폭(Q3 − Q1). 'IQR 1.5배'·'IQR 3배'는 Q3보다 IQR의 1.5배(3배) 넘게 크거나 Q1보다 그만큼 넘게 작은 값을 이상치 후보로 보는 기준이다.
- 평균±3표준편차: 평균에서 표준편차(값이 평균에서 흩어진 정도)의 3배보다 더 멀리 떨어진 값을 이상치 후보로 보는 기준이다.

## 5. 검정

해당 없음. 이 질문은 금액 합계와 비중을 구하는 기술분석이다 (규칙 6, 맥락 파일 메모 5 '기술분석').

- 규칙 5 (가)(나): 해당 없음 — 두 집단을 비교하는 검정을 하지 않는다.
- 규칙 5 (다) 이상치 포함·제외 비교: 분석 단계에서 다시 하지 않는다. 근거
  1. 코드북(2절·5절)에는 구입가격 이상치로 지목한 기록이나 기준이 없다. 값 범위 6000~38000만 적혀 있고, 모든 후보 값이 그 안에 있다.
  2. 기준이 없을 때 어떻게 할지는 승인 4번(원래 4번)에서 '유지, 판정 안 함'으로, 자료ID만 다른 행은 승인 5번(원래 5번)에서 '유지'로 정했다.
  3. 이 질문은 금액 '합계'라 큰 값이 결과를 움직일 수 있다. 그래서 점검 단계에서 선택지별 포함·제외·대체 수치를 이미 계산해 보였다. 비중은 모든 선택지에서 40.49%~40.54%였고, 기준값(유지)과의 차이는 이상치 쪽 최대 +0.01%p, 중복 쪽 최대 −0.04%p였다 (점검 값, 독립 검증 전; 점검.py 108~137, `점검/선택지별_핵심수치.csv` 2~10번째 줄).
  4. 규칙 5 (다)는 검정 결론이 이상치에 따라 달라지는지를 보는 것인데, 이 질문에는 검정 결론이 없다.
  - 이 점검 수치는 승인 10번(원래 10번)에 따라 결과.md와 최종 요약 '한계'에 '점검 단계 값, 독립 검증 전' 표시를 붙여 한 줄로만 인용한다 (7절). 핵심 수치로 넣지 않는다.
- 효과크기·95% 신뢰구간·검정 횟수: 해당 없음 (검정 0회). 이 파일 28,000행을 모두 더한 값이고 표본에서 추정한 값이 아니므로 신뢰구간을 붙이지 않는다.
- 방법을 고른 이유 (교수님 답변 5번, 요약 담당용): 질문이 '몇 %인가'를 묻는 현황 질문이므로, 무대출 책의 구입가격을 더해 전체 합계로 나누는 단순 비율로 답한다. 비교·추정을 하지 않으므로 검정이 필요 없다.

- 권수: 정수, 반올림 없음. 단위 '권'.
- 금액: 정수, 반올림 없음. 단위 '원'. 원 단위 그대로 보고한다 (승인 8번(원래 8번): 그래프도 원 단위 쉼표).
- 비중: 단위 '%'. 분자 ÷ 분모 × 100을 정확한 분수(`fractions.Fraction` 또는 `decimal.Decimal`)로 계산한 뒤, 소수 셋째 자리에서 사사오입(ROUND_HALF_UP)해 소수 둘째 자리까지 보고한다 (예: 12.345 → 12.35). Python 기본 `round()`(짝수 쪽 반올림)와 부동소수점 나눗셈 결과의 반올림은 쓰지 않는다.
- N7과 N8은 각각 따로 위 방식으로 계산한다. N8을 100 − N7로 구하지 않는다. 반올림한 N7 + N8이 100.00과 조금 다르게 나와도 값을 고치지 않고 그대로 둔다.
- 핵심수치.csv·검증값.csv: 열은 `번호,항목,값`. 권수·금액은 쉼표 없는 정수(예: 123456789)로, 비중은 반올림한 소수 둘째 자리 값(끝자리 0도 적는다, 예: 12.30)으로 쓴다. 반올림 전 값은 csv에 쓰지 않는다.
- 대조: 보고 자릿수에서 같으면 일치 (공통규칙 산출물 형식).

| 번호 | 항목 | 계산 방법 (필터 · 분모) | 단위·자릿수 |
|---|---|---|---|
| N1 | 전체 권수 | 입력 행 수 (필터 없음) | 권, 정수 |
| N2 | 무대출 권수 | `구입일` ≤ 2022-12-31 이고 `대출횟수` == 0인 행 수 | 권, 정수 |
| N3 | 나머지 권수 | 무대출 조건에 맞지 않는 모든 행 수. N1 − N2로 구하지 말고 조건으로 직접 센다 | 권, 정수 |
| N4 | 무대출 구입가격 합계 | N2 조건 행의 `구입가격` 합 | 원, 정수 |
| N5 | 나머지 구입가격 합계 | N3 조건 행의 `구입가격` 합 (직접 더한다) | 원, 정수 |
| N6 | 구입가격 합계(현재 목록 28,000권) | 입력 28,000행 모두의 `구입가격` 합 (필터 없음, 직접 더한다) | 원, 정수 |
| N7 | 무대출 비중 | N4 ÷ N6 × 100 | %, 소수 둘째 자리 |
| N8 | 나머지 비중 | N5 ÷ N6 × 100 | %, 소수 둘째 자리 |
| N9 | 무대출 정의 어긋남 수 | `구입일` ≤ 2022-12-31인 행 안에서 (`최근대출일` 빈칸) XOR (`대출횟수` == 0)인 행 수. 0이어야 한다 | 권, 정수 |

합 확인 (핵심 수치 아님, 분석·검증이 각자 확인. 어긋나면 멈추고 보고)
- N1 = 28,000 (다르면 멈춤)
- N2 + N3 = N1
- N4 + N5 = N6
- N9 = 0

핵심 수치 개수: 9개 (N1~N9). 승인 10번(원래 10번)으로 N10~N13(품질 선택지별 비중)은 만들지 않는다. 승인 8번(원래 8번, 원 단위)으로 그래프에 반올림한 새 표기 값이 생기지 않으므로, 표기 값용 N 번호도 따로 두지 않는다.

## 9. 제안 (계산명세에 넣지 않음, 수행하지 않음)

- 무대출·나머지의 권수 비중을 금액 비중 옆에 함께 보이는 것 — 금액 비중과 권수 비중이 비슷한지 볼 수 있지만 요청받지 않았다 (점검에서 두 비중 차이 −0.05%p, 점검 값, 독립 검증 전; `점검/선택지별_핵심수치.csv` 2번째 줄).

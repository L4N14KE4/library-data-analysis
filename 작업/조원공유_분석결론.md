작성: 요약 담당 / 2026-11-25
읽는 사람: 5조 조원 전원

## 이 문서는

지금까지 확정한 분석 다섯 개와 결정표를 장마다 같은 틀로 정리한 문서다. 장마다 무엇을 물었는지, 어떤 기준과 정의를 썼는지, 어떤 방법을 왜 골랐는지, 무엇이 나왔는지, 어떻게 읽어야 하는지를 적었다.

- **데이터**: `P02_장서목록_대출횟수 original.csv` 28,000권 (1행 = 책 1권). 대출 값은 2023~2025년 3년간 대출된 횟수를 합친 **한 칸**뿐이다. 그래서 해마다 늘었는지 줄었는지는 어느 장에서도 말할 수 없다.
- **모든 분석 수치는 독립 재계산이 일치한 값이고, 재현은 2~5장에서 일치했다** (1·6장은 재현 해당 없음 — 1장은 분석 코드가 없고, 6장은 계산 없이 옮긴 정리 문서다). 6장의 후보 수·한계 수는 재계산 대상이 아닌 문서 구조의 개수다. 수치 옆 [Nk]는 그 장 폴더 `분석/핵심수치.csv`의 번호다 (1장은 `점검/핵심수치.csv`). N 번호가 없는 값은 그 자리에 출처를 적었다.
- 분석 실행과 문서 초안은 AI(Claude Code)가 했다. 정의·품질 처리·분석 방법과 해석 문장은 팀이 항목별로 승인했다 (각 폴더 승인기록.md에 답 원문). 결정표의 후보 고르기와 '팀이 채움' 칸은 팀이 기획회의에서 한다.
- 이 문서에서 새로 계산한 수치는 없다. 두 값을 빼거나 나눈 값도 새로 만들지 않았다. 차이 값은 분석에서 따로 계산해 검증한 것만 옮겼다 (4장 N745~N752, 5장 단가 차이 N23·N24).
- **장마다 대상이 다르다.** 2장은 구입일 2022-12-31 이하 22,699권, 3장은 28,000권을 무대출/나머지로 나눈 것, 4·5장은 28,000권 전부다. 대상이 다른 장의 수치는 더하거나 견주지 않는다.

- **대출횟수**: 2023~2025년 3년간 그 책이 대출된 횟수. '이용', '수요', '인기', '가치'와 같은 말이 아니다. 관내 열람처럼 대출이 아닌 쓰임은 이 자료에 없다 (코드북 7절 ③).

## 1장. 공통 정제 — 결측·이상치·중복 점검

### 1. 무엇을 물었나

원자료 28,000행의 사용 변수 8개에서 결측치(값이 빠진 칸)를 점검하고, 처리 방법(제외 / 대체 / 유지)을 정해 코드북 4절 정제 이력에 기록한다. 점검 범위는 이상치와 중복까지 넓혔다 (승인 1·3번).

### 2. 기준과 정의

| 항목 | 내용 |
|---|---|
| 대상 | 원자료 28,000행 [N1] 전부 |
| 쓰는 열 | 15열 [N2] 가운데 8열 [N3]: 자료ID, 발행년, KDC, 주제분류명, 구입일, 구입가격, 대출횟수, 최근대출일 |
| 뺀 열 | 코드북 1-1절 '삭제' 7열 (서명, 저자, 출판사, 자료구분, 소장관, 이용상태, 장서연령). 원자료 파일은 그대로 두고 코드에서만 뺐다 |
| 결측의 기준 | 코드북 2절·5절. 최근대출일 빈칸만 결측으로 정해져 있다 |
| 이상치 | 공통 정제에서는 판정하지 않음 (코드북에 기준 없음) |
| 중복 | 자료ID가 같은 행, 그리고 자료ID만 다르고 나머지 7열이 모두 같은 행 |

### 3. 어떤 방법을 왜 골랐나

- **방법**: 문제마다 해당 행 수를 세고, 처리 선택지(제외 / 대체 / 유지)와 그 선택에 따른 수치 차이를 보인 뒤 팀이 고르게 했다. 공통규칙 4(결측·이상치·중복은 임의로 처리하지 않는다)를 따른 절차다.
- **최근대출일 빈칸 유지** (승인 4·19번): 빈칸인 행이 대출횟수 0인 행과 정확히 같아서, 지우면 3년간 대출 0회인 책이 모두 빠지기 때문이다 (정제이력.md 4절 #1).
- **통계적 이상치는 판정하지 않음** (승인 6·14번): 코드북에 기준이 없기 때문이다 (정제이력.md #5). 기준은 이상치가 필요한 분석(4·5장)에서 따로 승인받았다 (이 문장은 코드북 문안에는 넣지 않기로 했다 — 공통 정제 승인 21번).
- **자료ID만 다른 16쌍(32행) 유지** (승인 8번): 8개 열만으로는 같은 책이 두 번 들어간 것인지 구별할 수 없기 때문이다 (정제이력.md #4).
- **코드북과 데이터가 다른 곳은 데이터를 두고 코드북을 고침** (승인 7번): 근거는 팀 결정으로만 적혀 있다.
- 점검 범위를 이상치·중복까지 넓힌 이유: 근거 기록 없음 (승인 3번에 선택만 있다).

### 4. 결과

| 항목 | 값 |
|---|---|
| 지운 행 | 0행 [N19] — 정제 뒤에도 28,000행 [N18] |
| 최근대출일 빈칸 | 14,036행 [N4] |
| 빈칸이면서 대출횟수 0 / 빈칸이면서 1 이상 / 값이 있으면서 0 | 14,036 [N5] / 0 [N6] / 0 [N7] |
| 그 밖의 변수의 빈칸 | 0칸 [N8] |
| 논리적으로 불가능한 값 (최근대출일 < 구입일 등) | 0행 [N10·N11·N12] |
| 자료ID가 겹치는 행 | 0행 [N13] |
| 자료ID만 다르고 나머지 7열이 같은 행 | 32행 [N14] (16쌍, 모두 최근대출일 빈칸·대출 0회) |
| 최근대출일 = 구입일 | 712행 [N15] (정상으로 보고 유지) |

### 5. 어떻게 읽어야 하나

- 사실: 행을 하나도 지우거나 바꾸지 않았다. '처리'는 모두 유지, 처리 안 함(빈칸 유지), 처리할 것 없음, 판정하지 않음 가운데 하나다.
- 사실: 최근대출일 빈칸은 '최근에 대출된 기록이 없음'이다. 빈칸 = 대출 0회라는 것이 데이터로 확인되었다 [N5~N7].
- 흔히 틀리게 읽는 것: '정제했다 = 이상한 책을 뺐다'가 아니다. 이 단계에서 이상치는 판정하지 않았다.
- 교수님 답변 2번(2026-11-25)에 따라, 삭제 7열은 '비식별 처리'가 아니라 **정제 이력**으로 부른다 (승인 24번, 정제이력.md #10).

### 6. 검증

독립 재계산 20/20 일치. 재현(8.5단계) 해당 없음 — 분석 코드가 없다 (검증 담당이 정제 코드와 재계산 코드를 다시 돌려 같은 CSV가 나온 것은 확인했다, 대조표 7줄).

## 2장. 질문 1 — 3년 무대출 책의 주제별 분포

### 1. 무엇을 물었나

28,000권 가운데 구입일이 2022-12-31 이하이면서 2023-01-01~2025-12-30 3년간 대출횟수가 0인 책(무대출)은 몇 권이고, 주제분류명 10개 가운데 어디에 얼마나 있는가 (승인 7번).

### 2. 기준과 정의

| 항목 | 내용 |
|---|---|
| 대상 | 구입일 2022-12-31 이하 22,699권 [N2] (전체 28,000권 [N1] 가운데) |
| 무대출 | 대상이면서 대출횟수 0 (= 최근대출일 빈칸, 어긋나는 책 0권 [N5]) |
| 기간 | 2023-01-01~2025-12-30 |
| 뺀 것 | 2023-01-01 이후 구입한 책 (무대출 판단 대상이 아님), 삭제 7열 |
| 주제 안 무대출 비율 | 그 주제 무대출 권수 ÷ 그 주제 대상 권수 |
| 무대출 전체 중 비중 | 그 주제 무대출 권수 ÷ 무대출 전체 11,363권 |

### 3. 어떤 방법을 왜 골랐나

- **방법: 기술분석** — 검정 없이 권수를 세고 비율을 구해 표로 정리하는 방법이다.
- 고른 이유: 맥락 파일 메모 1의 분석 유형이 '기술분석'이고, 권수와 비율을 세는 질문이라 비교 검정이 필요 없다 (계산명세 5절). 28,000행을 모두 센 값이라 표본에서 추정할 때 쓰는 신뢰구간도 붙이지 않았다. (95% 신뢰구간: 같은 방법으로 조사를 반복하면 100번 중 약 95번은 실제 값을 포함하도록 만든 범위.)
- '최근 대출일이 3년을 넘어간 책'을 '3년간 대출 0회'로 잰 이유: 데이터에 2023년 전 대출 기록이 없어서 그렇게만 잴 수 있다 (질문.md).
- 기준일 2022-12-31: 질문 원문 '2022년 이전 도서'를 2022-12-31까지 구입으로 읽었다 (승인 3번). 2021-12-31로 읽는 안 대신 이것을 고른 이유: 근거 기록 없음 (질문.md '1단계 답변' 표와 계산명세 2절에도 '승인 3번'만 적혀 있다).
- 분모를 두 개 다 표에 넣은 이유: 승인 4번(둘 다 넣기), 승인 9번(대상 권수 열과 합계 행 — 분모가 표에 보여 두 비율을 섞어 읽을 일이 줄어든다, 계산명세 8절).
- 이상치 비교는 해당 없음: 대출횟수가 0인지 여부만 쓰므로 큰 값이 결과를 바꾸지 않는다 (계산명세 5절).

### 4. 결과

| 항목 | 값 |
|---|---|
| 무대출 권수 | 11,363권 [N3] |
| 전체 28,000권 대비 | 40.58% [N4] (분모에 2023년 이후 구입 책 포함) |
| 대상 22,699권 대비 | 50.06% [N56] |
| 무대출 권수 가장 많은 / 적은 주제 | 기술과학 2,203권 [N7] / 종교 310권 [N42] |
| 주제 안 무대출 비율 가장 높은 / 낮은 주제 | 총류 65.06% [N53] / 문학 35.33% [N13] |
| 문학 | 무대출 권수 1,970권 [N12](10개 중 두 번째로 많음)인데 주제 안 비율은 가장 낮음 |

전체 표(10개 주제)는 `작업/20261117_무대출_주제분포/최종요약.md` 2-2절.

### 5. 어떻게 읽어야 하나

- 사실: 무대출 권수(어디에 많이 모여 있나)와 주제 안 비율(그 주제 안에서 얼마나 되나)은 다른 그림을 보여 준다. 문학은 권수로는 두 번째로 많고 비율로는 가장 낮다. 문학은 대상 권수가 5,576권 [N11]으로 가장 많다.
- 사실: 기술과학은 무대출 권수가 가장 많고(2,203권 [N7]) 주제 안 비율도 64.97% [N8]로 높은 쪽이다.
- [추정] 어느 지표를 쓰느냐에 따라 기획회의에서 먼저 논의할 주제가 달라질 수 있다. 기술과학은 두 지표 어느 쪽으로 보아도 먼저 논의할 주제로 꼽힐 수 있다. 이것은 제적·정리 대상이라는 뜻이 아니다.
- 흔히 틀리게 읽는 것
  - **'무대출 = 가치 없는 책·제적 대상'이 아니다.** 3년간 대출 기록이 없을 뿐이다 (맥락 파일 메모 2 ✕, 코드북 7절 ①③).
  - **'주제 때문에 무대출이 많다'가 아니다.** 주제와 무대출이 함께 나타나는 정도(관련)만 보았다. 주제마다 소장 기간이 다를 수 있는데 그것으로 나누어 보지 않았다.
  - **40.58%와 50.06%를 바꿔 쓰지 않는다.** 분모가 다르다. 합계 행 50.06%는 10개 주제 비율의 평균도 아니다.

### 6. 검증

독립 재계산 56/56 일치, 재현 56/56 일치.

## 3장. 질문 5 — 무대출 책의 구입가격 비중

### 1. 무엇을 물었나

질문 1과 같은 무대출 책의 구입가격 합계는 얼마이고, 28,000권 구입가격 합계에서 몇 %를 차지하는가 (승인 3번).

### 2. 기준과 정의

| 항목 | 내용 |
|---|---|
| 무대출 | 질문 1과 같다: 구입일 2022-12-31 이하 + 2023~2025년 대출횟수 0 → 11,363권 [N2] |
| 나머지 | 그 밖의 모든 책 16,637권 [N3] (2023년 이후 구입한 책 포함) |
| 분모 | '구입가격 합계(현재 목록 28,000권)' = 이 파일 28,000행 [N1]의 구입 당시 단가의 합 (구입가격은 코드북 2절의 '자료 구입 단가'이고, 구입 당시 값이라는 것은 질문 5 승인 2번의 읽기다). 도서관 예산 집행액도, 현재 가치도 아니다 (승인 7번) |

### 3. 어떤 방법을 왜 골랐나

- **방법: 기술분석** — 두 묶음(무대출 / 나머지)의 구입가격을 더하고, 전체 합계에서 차지하는 비중을 구했다. 결과는 두 조각 원그래프로 보였다.
- 고른 이유: 맥락 파일 메모 5의 분석 유형이 '기술분석'이고, 합계와 비중을 구하는 질문이라 검정이 필요 없다 (계산명세 5절).
- 무대출 정의를 질문 1과 같게 둔 이유 (승인 1·6번): 질문 1과 같은 무대출 책을 이어 읽기 위해서다 (계산명세 2절). 맥락 파일 메모 5의 문구('대출 횟수가 0인 장서', 구입일 조건 없음)와 다르다는 점은 보고서에 적기로 했다. (교수님 답변 1번: "의도는 같은 정의이나, 다르게 해석해도 무방함" — 지금 정의를 바꿀 필요는 없다.) 원래 근거 문장 하나는 측정하지 않은 표현이라 옮기지 않았다 (분석목록_다시하기.md 5절).

## 4장. 질문 3 — 발행년·주제별 대출횟수와 적게 대출된 책의 특징 (28,000권)

### 1. 무엇을 물었나

28,000권 전부를 대상으로 ① 발행년별(2005~2025)·주제별 대출횟수 총합과 평균을 평균 오름차순으로 정리하고, ② 발행년·주제 사이 차이가 우연만으로도 나올 수 있는지 검정하고, ③ 자기 발행년 평균보다, 또 자기 주제 평균보다 적게 대출된 책의 특징을 나머지 책과 비교한다. 원인('오래돼서', '주제 탓')은 말하지 않는다 (승인 4번).

### 2. 기준과 정의

| 항목 | 내용 |
|---|---|
| 대상 | 28,000권 전부 [N2] (구입일로 거르지 않음, 승인 1번) |
| 이상치 | 대출횟수가 '대상 전체 평균 2.5125회 [N3] + 표준편차 10.1682회 [N4] × 3' = 33.0172회 [N6]를 넘는 책 → 34회 이상 210권 [N7]. 표준편차는 값이 평균에서 흩어진 정도다. 코드북에 기준이 없어 팀이 승인한 비교 기준이다 (승인 5번) |
| 두 처리 | **유지** = 28,000권 전부 (주 결과), **평균±3SD 제외** = 210권을 뺀 27,790권 [N8] (비교 결과) |
| 고른 책 A / B | A = 자기 발행년 평균보다 대출횟수가 적은 책, B = 자기 주제 평균보다 적은 책. 나머지 = 고르지 않은 책 |
| 2023년 이후 구입분 | 구입일 2023-01-01 이후 책 5,301권 [N158] (18.93% [N159]). 구입 전에는 대출될 수 없어, 3년 가운데 대출될 수 있었던 기간이 짧다 |
| 뺀 것 | 삭제 7열. 행은 하나도 빼지 않음 (16쌍 32행도 유지, 승인 6번) |

### 3. 어떤 방법을 왜 골랐나

먼저 알아 둘 말
- **p값**: '집단들에 실제로는 차이가 없다'고 가정했을 때 이번 정도의 차이가 우연히 나타날 확률이다. '차이가 우연일 확률'이나 '틀렸을 확률'이 아니다. 0.05보다 작으면 '이 자료로 차이를 확인했다'고 쓴다.
- **모수검정과 비모수검정**: 모수검정은 평균 같은 값 자체를 비교하는 검정이고, 비모수검정은 값을 순위로 바꾸어 비교해 큰 값 몇 개에 덜 휘둘리는 검정이다. 두 검정은 서로 다른 질문에 답한다. 어느 쪽 질문인지 분명하지 않으면 둘 다 한다 (공통규칙 5).
- **95% 신뢰구간**: 같은 방법으로 조사를 반복하면 100번 중 약 95번은 실제 값을 포함하도록 만든 범위.
- **IQR(사분위범위) 기준**: 값을 크기순으로 놓았을 때 아래에서 25% 지점을 Q1, 75% 지점을 Q3라 하고, 그 사이 폭(IQR = Q3 − Q1)을 잰다. Q1보다 아래로, 또는 Q3보다 위로 IQR의 1.5배(또는 3배)보다 멀리 떨어진 값을 이상치로 보는 기준. 평균±3SD와 함께 이상치 기준의 후보였다.

| 방법 | 한두 문장 설명 | 고른 이유 |
|---|---|---|
| 웰치 분산분석 (모수검정) | 여러 집단의 **평균** 대출횟수가 모두 같다고 볼 수 있는지 묻는다. 집단마다 흩어진 정도(분산)가 같다고 가정하지 않고 계산한다 | 질문이 평균을 쓰므로 평균 차이를 직접 묻는 검정이 필요하다. 집단마다 표준편차가 크게 달라, 같은 분산을 가정하는 일반 분산분석은 맞지 않는다 (계산명세 5-2절) |
| 크러스컬-월리스 검정 (비모수검정) | 값을 순위로 바꾸어, 대출횟수가 큰 쪽에 놓이는 경향(순위 분포)이 집단마다 같은지 묻는다. 평균 비교가 아니다. 대상의 약 절반이 0회라 같은 값(동점)이 매우 많고, 그만큼 순위로 얻는 정보가 줄어든다는 한계가 있다 | 분포가 한쪽으로 크게 치우쳐 있고 큰 값 몇 권에 평균이 끌리므로, 큰 값에 덜 휘둘리는 순위 비교를 함께 본다. 동점이 많아 동점 보정이 들어간 방법을 쓴다 (계산명세 5-2절) |
| 효과크기 η²·ε² | 차이가 **얼마나 큰지**(0~1). η²는 값의 흩어짐 가운데 집단 평균 차이로 갈리는 몫, ε²는 순위의 흩어짐 가운데 집단 차이로 갈리는 몫 | 28,000권이면 아주 작은 차이도 p < 0.05가 되기 쉬워, 크기를 따로 읽어야 한다 (계산명세 5-5절) |
| 95% 신뢰구간 (부트스트랩, 백분위수 방식) | 집단마다 그 집단 권수만큼, 뽑은 책을 다시 넣으며 뽑기(복원추출)를 5000번 해 효과크기를 5000번 다시 계산하고, 그 5000개 값의 아래 2.5%·위 2.5% 지점을 구간으로 썼다. 시드(무작위 뽑기를 같은 순서로 다시 하게 하는 시작 값)는 20261117 | 다른 방식인 BCa(치우침과 가속을 보정한 부트스트랩 구간)는 행마다 다시 계산해야 해서 28,000행에서 너무 오래 걸린다 (계산명세 5-3절) |
| 이상치 유지·제외 두 처리 | 이상치를 넣은 결과와 뺀 결과를 모두 낸다 | 공통규칙 5 (다). 코드북에 기준이 없어 평균±3SD를 승인받았다 (승인 5번). IQR 기준 대신 평균±3SD를 고른 이유: 근거 기록 없음 (이 판 승인 5번과 보관판 승인 6번 모두 선택지와 선택만 있다) |

- 신뢰구간을 읽을 때: η²·ε²는 0보다 작을 수 없어 구간 하한이 늘 0보다 크다. 그래서 '구간이 0을 포함하지 않는다'를 차이의 근거로 읽지 않는다. 백분위수 방식은 작은 효과크기의 구간을 위로 치우치게 잡을 수 있다 (계산명세 5-3절).
- 정규성 검정(자료가 정규분포를 따르는지 보는 검정)은 하지 않았다. 분포가 정규분포와 멀다는 것이 분명하고, 집단 크기가 수백~수천이면 정규성 검정 p값이 아주 작은 어긋남에도 작게 나와 근거가 되지 못하기 때문이다 (계산명세 5-1절).
- 다중 비교 보정(검정을 여러 번 할 때 우연히 '차이를 확인했다'가 나올 가능성을 줄이는 조정)은 하지 않았다. 검정은 8회(발행년·주제 × 두 방법 × 두 처리)인데, 발행년과 주제는 다른 질문이고, 두 방법은 같은 질문을 두 시각으로 본 것이며, 제외 처리는 민감도 확인이기 때문이다 (계산명세 5-5절).
- 사후 비교(어느 집단과 어느 집단이 다른지)는 하지 않았다. 고른 선택지: '안 함(전체 검정 8회만)', '주제 쌍만 비교', '발행년 쌍과 주제 쌍 모두 비교' 가운데 '안 함'. 왜 안 하는지를 적은 이유 문장은 없다 (이 판 승인 11번이 보관판 승인 13번을 이어받음).
- 고른 책을 '자기 집단 평균보다 적은 책'으로 정한 것은 확정 질문 문장 그대로다. 고른 선택지: '정의를 그대로 두고, 고른 책이 실제로 몇 회 대출된 책인지 사실을 결과에 밝힌다'와 '대출 0회 책으로 바꾼다' 가운데 앞의 것. 왜 평균을 기준으로 하는지를 적은 이유 문장은 없다 (이 판 승인 4·8번, 보관판 승인 8번).
- 2005~2022년만 따로 검정하는 것은 더하지 않았다. 2023~2025년 세 해와 관련된 해석의 한계는 해석 제한 문장(아래 5절 첫 경고)으로 다룬다 (승인 12번).

## 5장. 질문 4 — 주제별 대출·가격과 2027년 예산 배분 근거 (28,000권)

### 1. 무엇을 물었나

28,000권 전부를 대상으로 2027년 자료구입 예산의 주제 배분 근거를 정리한다: 주제별 장서 수·대출 평균·중앙값, 평균±3표준편차 이상치와 주제별 쏠림, 자료 구입 단가 비교, 근거 지표(대출 비중·권수 비중·구입가격)와 정해진 식의 배분 비율 시나리오. 어느 시나리오를 쓸지는 팀이 기획회의에서 정한다. 예측과 예산 금액은 만들지 않는다 (승인 3번).

### 3. 어떤 방법을 왜 골랐나

- **방법: 기술분석 + 정해진 식의 비율 계산** — 주제별로 세고 평균·비중을 구한 뒤, 미리 정한 식 4개(7개 열 — 시나리오 1·2·4는 유지·제외 두 열, 3은 대출을 쓰지 않아 한 열)로 배분 비율을 계산했다. 검정은 0회다.

  - 시나리오 1 — 대출 비중대로: 예산 구성을 2023~2025년 대출 구성과 같게 둔다. 책값 차이는 반영하지 않는다.

## 6장. 결정표와 한계 — 기획회의 재료

### 1. 무엇을 물었나

사례 A의 관장이 결정할 두 가지 — ① 2027년 자료구입 예산의 주제 배분, ② 장서 정리 방향 — 에 대해, 확정 분석 4개(2~5장)의 검증된 수치만으로 결정표, 제안 틀, 한계와 다음에 모을 데이터를 한 파일로 정리한다 (승인 1~3번).

### 2. 기준과 정의

| 항목 | 내용 |
|---|---|
| 재료 | 2~5장의 확정 결과만 (보관판은 '보관판에 있다'만 적음, 승인 1·4번) |
| 수치 | 새로 계산하지 않음. 금액(원 단위 예산)을 만들지 않음 |
| 후보 | 세부 결정마다 후보를 우열 없이 나열하고, 고르는 것은 팀 (승인 2번) |
| 대상 | 질문마다 대상이 달라, 대상이 다른 수치는 더하거나 견주지 않음 |

### 3. 어떤 방법을 왜 골랐나

- **방법: 정리** — 계산은 하지 않고, 세부 결정마다 (가) 데이터가 뒷받침하는 것, (나) 그 앞에서 멈추는 까닭, (다) 팀이 판단할 후보를 적었다.
- 후보를 나열하는 방식으로 한 이유: 사용자가 '빈칸 + 팀이 정할 물음' 대신 '선택지 후보까지'를 골랐다 (승인 2번). 형식은 팀 프로젝트 운영 가이드라인 v15의 장면 5·5절 구성을 따른다 (질문.md).

## 전체 결론 요약

1. 정제에서 지운 행은 없다. 최근대출일 빈칸은 대출 0회와 정확히 같은 책이다 (1장).
2. 구입일 2022-12-31 이하 22,699권 가운데 3년 무대출은 11,363권이고, 이 책들의 구입가격 합계는 현재 목록 28,000권 구입가격 합계의 40.53%다. 무대출 권수가 가장 많은 주제(기술과학)와 주제 안 무대출 비율이 가장 높은 주제(총류)가 다르다 (2·3장).
3. 28,000권에서 주제·발행년과 대출횟수의 관련은 확인됐으나 크기는 '작음' 이하이고, 2023~2025년 발행 책의 낮은 평균은 대출될 수 있었던 기간이 짧은 것과 떼어 볼 수 없다 (4장).
4. 대출 비중은 문학이 가장 크고, 소수의 이상치 책(210권)이 대출 합의 24.91%를 차지해 유지·제외에 따라 값과 순위가 움직인다. 배분 비율은 정해진 식의 시나리오까지이며 금액이 아니다 (5장).
5. 어느 시나리오·지표를 쓸지, 무대출을 어떻게 다룰지는 팀이 기획회의에서 정한다. 어느 결과도 원인이나 책의 가치를 말하지 않는다 (6장).

## 2. 다시 하는 두 가지 방법

### 2-1. 코드만 다시 돌려 같은 값이 나오는지 보기 (8.5단계 재현)

프로젝트 폴더(`data-litaracy/`)에서 실행한다. 분석 코드는 결과를 `분석/`에 덮어쓰므로, 먼저 `분석/`을 복사해 두고 비교한다.

```bash
.venv/bin/python 작업/20261117_무대출_주제분포/분석/분석.py
```

```bash
.venv/bin/python 작업/20261117_무대출_구입비비중/분석/분석.py
```

```bash
.venv/bin/python 작업/20261118_발행년주제_대출횟수_전체도서/분석/분석.py
```

```bash
.venv/bin/python 작업/20261118_주제별_예산근거_전체도서/분석/분석.py
```

- 질문 3은 부트스트랩(시드 20261117, 5000회) 때문에 2~5분 걸린다. 나머지는 몇 초다.
- 필요한 것: `.venv`(Python 3.11.13, pandas 3.1.1, numpy 2.4.6, scipy 1.17.1, matplotlib 3.11.2 — `requirements.txt`), 원자료 `P02_장서목록_대출횟수 original.csv`, 폰트 `NanumGothic.ttf`(git에 없음, 따로 받는다).
- `.venv`에는 pip가 없다. 버전은 `importlib.metadata`로 확인한다 (각 폴더 승인기록 '8.5단계' 행).
- 2026-11-18 결과: 네 곳 모두 바이트 단위로 같았다 (각 폴더 `검증/재현.md`).

### 2-2. 절차를 처음부터 다시 밟기 (1~9단계)

새 세션에서 "질문 n 시작"처럼 요청한다. CLAUDE.md '이미 한 분석을 다시 할 때'(사용자 지시, 2026-11-25)에 따라, 진행 담당은 그 질문 폴더 승인기록.md의 결정을 그대로 적용하고 묻지 않고 진행한다.
- 새 폴더의 승인기록.md에는 행마다 '이전 결정 적용 (사용자 지시 2026-11-25)'과 원래 폴더·승인 번호·사용자 답 원문을 적는다.
- 묻지 않는 것은 팀이 이미 내린 판단을 다시 적용하기 때문이다. 판단을 AI에게 맡기는 것이 아니다. 그래서 새 판단이 필요한 자리에서는 멈추고 묻는다.
  - 원자료·코드북·맥락 파일이 바뀌었을 때
  - 이전 결정이 다루지 않은 품질 문제가 나왔을 때
  - 값이 이전 최종요약과 다르거나, 검증·재현이 맞지 않을 때
  - 처음 하는 질문일 때
